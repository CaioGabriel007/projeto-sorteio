<h2> Um sorteador simples, mas funcional aplicando técnicas de JS para aperfeiçoar nossos conhecimentos no objetivo de dominar a DOM</h2>

<p><i>Neste projeto aplicamos principalmente, as ferramentas de "math" principais com destaque no math.random onde trabalhamos com números aleatórios.</i></p>
